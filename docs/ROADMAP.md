# Roadmap

Server features and deliberate storage/session limits are tracked in [Fuel](https://github.com/Xanders/fuel/blob/main/docs/ROADMAP.md).

Future companion work: platform-certified secure-storage adapters; device/browser acceptance matrix; guild/achievement/community/purchase facades alongside released server contracts; measured consumer integration fixtures; registry publication. Do not add placeholder APIs for unreleased server features.

No cross-instance session support or automatic restore of RAM state is promised.
