# Roadmap

Server features and deliberate storage/session limits are tracked in [Fuel](https://github.com/Xanders/fuel/blob/main/docs/ROADMAP.md).

Released Flutter helpers include input rearm and shared audio lifecycle policy. Consumer-specific key/axis mapping, focus, cue selection and media catalogs remain outside those helpers.

Future companion work: platform-certified secure-storage adapters; device/browser acceptance matrix; guild/achievement/community/purchase facades alongside released server contracts; measured consumer integration fixtures; optional bounded media leases and small settings/UI helpers where multiple consumers demonstrate the same policy; validation of audio policy with a Flutter-only client; registry publication. Do not add placeholder APIs for unreleased server features.

No cross-instance session support or automatic restore of RAM state is promised.
